## 🎯 Execução Simples

### Opção 1 - Script Automático
```powershell
.\instalar.ps1
```

### Opção 2 - Manual (2 Terminais)

**Terminal 1 - Backend:**
```powershell
cd backend
npm run dev
```

**Terminal 2 - Frontend:**
```powershell
cd frontend
npm start
```
